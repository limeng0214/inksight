# 微雪 3.97 英寸五页课桌

目标为 ESP32-S3-ePaper-3.97 一体板，800 × 480 黑白横屏。用 USB 供电。上拨/下拨翻页，中按执行当前页操作。

| 页面 | 使用 |
|---|---|
| 明日课程 | 联网校时后显示明天的星期和日期。中按继续看后一天。包括周二钢琴、周三在线英语、周四和周五晚自习。 |
| 英文时钟 | 显示北京时间、英文日期和星期，12 小时制。分钟变化时局部刷新。中按切换诗文与注解。 |
| 每日阅读 | 七篇本地短文按日轮换，中按查看问题提示。 |
| 睡前打卡 | 中按开始、暂停或继续 6 分钟计时。到时自动返回睡前页，中按依次勾选右侧的滴眼药水、刷牙、洗脚、戴 OK 镜。 |
| 爸妈留言 | 手机连接同一家庭 Wi-Fi，在浏览器输入页面右上角的 IP（使用 http）。选择日期，每行填写一条并保存。设备按日期直接读取本机存储的留言，同屏编号。清空文字再保存即可删除当天留言。 |

11 月 21 日校时后显示生日卡。中按进入日常页面。首次配置 Wi-Fi 仍使用原项目的 InkSight 配网热点。留言编辑服务运行在板子上，适用于可信家庭网络；同一局域网内能访问设备地址的人均可编辑。此版本没有使用网站账户或外网转发。诗词与阅读为内置内容，首次上电需要联网校时才能确定实际日期。

在 firmware 目录运行 `pio run -e jiayi_397_s3`。刷机可用 `pio run -e jiayi_397_s3 -t upload`；构建生成的完整文件 `firmware_merged.bin` 从地址 0x0 烧录。通用 InkSight 配置为 `epd_397_waveshare_s3`。

[规格演示](demo.html) 可下载后打开。演示的家长后台保存在浏览器内，实物使用上面的局域网编辑页。
