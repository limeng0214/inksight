# 3.97 英寸桌面

[五页交互演示](demo.html) 可下载后在浏览器打开。使用上拨、下拨和中按按钮体验明日课表、英文时钟与古诗、每日阅读、睡前打卡和编号留言。留言在浏览器本地模拟保存。

当前嵌入式桌面来自本地三页版，包含课程表、阅读和睡前计时，生日当天附加生日卡。五页演示是后续产品规格，英文时钟页、右侧四项清单及家长留言仍待移植和上板验证。

在 firmware 目录执行 `pio run -e jiayi_397_s3` 编译桌面版本。通用版继续使用 `epd_397_waveshare_s3`。桌面使用微雪 ESP32-S3-ePaper-3.97 一体板。发布示例的生日卡使用通用称呼。
